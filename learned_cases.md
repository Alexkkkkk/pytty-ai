# Сохранённые удачные решения (обучение)

Сюда программа дописывает случаи по кнопке
«Сохранить успешное решение в базу знаний».
Этот файл подхватывается ИИ автоматически при запуске.

## Удачный случай (пример шаблона)

Проблема (фрагмент вывода терминала):

```
** Bad signature on 0:1: expected 0x5840, got 0x0000
** partition 0 not valid on device 0
```

Решение (команды по порядку):

```
usb stop
usb start
usb part
fatls usb 0:1 /
usb_super_upgrade_to_emmc
reset
```
