# База знаний: сервис ТВ-прошивок, EJTAG, программаторы

Источник для обучения и пополнения: форум **www.ejtag.ru** (поддержка
программаторов Tiny Tools: USB-F / USB-SPI / EASY-NAND / eJfinder; разделы
дампов eMMC/NAND, адаптеров BGA, типовых неисправностей). Дампы и распиновки
брать там; ниже — выжимка методики, которую должен знать ИИ.

## Программаторы и инструменты

| Инструмент | Назначение |
|---|---|
| RT809F / RT809H | универсальный (SPI/NOR/NAND/eMMC через адаптеры), стандарт сервиса |
| CH341A + переходники | бюджет SPI/NOR (24/25xx), eMMC через адаптеры с подтяжкой |
| Tiny Tools EASY-NAND / USB-SPI / USB-F | NAND TSOP48 / SPI / eMMC NAND (форум ejtag.ru) |
| eJfinder | поиск и идентификация чипов, сигнатуры NAND/eMMC |
| USB-UART (CP2102/FT232/CH340) | консоли загрузчиков (см. boot_profiles.py), 3.3 В |
| Тест-карта eMMC-NAND BGA | адаптеры под распайку BGA169/153, чтение в-circuit/выкус |

## Практические правила прошивки ТВ

1. **Сначала дамп, потом стирание.** Всегда читать полный дамп eMMC/NAND
   до любой записи и сохранять (заводские MAC, SN, ключи DRM/HDCP/Widevine
   не восстановимы без бэкапа).
2. **eMMC читать/писать разделами или целиком** с корректным размером
   user data; boot0/boot1/RPMB — отдельно. Смещения GPT брать из дампа.
3. **NAND**: обязательно сохранять spare area (OOB) — ECC и загрузочный
   код могут лежать там; прошивать с тем же размером страницы/блока,
   что и у донора дампа.
4. **In-circuit (без выкуса):** питание целевой платы не подавать от
   программатора без проверки; конденсаторы по питанию, короткие провода,
   часто нужно удерживать SoC в reset (подтяжка RES/#RST) или отпаять
   кварц/подать питание только на eMMC.
5. **Выкус (BGA):** если плата не пускает шину (SoC держит линии),
   только выкус + адаптер + реболл/пайка обратно.
6. **После прошивки:** первый запуск дольше обычного (расширение разделов,
   first boot); не выключать.

## Типовые неисправности ТВ (и что делать в первую очередь)

| Симптом | Диагностика | Действие |
|---|---|---|
| Зависание на логотипе | UART-лог: где останавливается boot | MStar: `recovery_wipe_partition cache` → `data`; иначе дамп eMMC |
| Bootloop, циклическая перезагрузка | лог до момента ребута | wipe cache/data, проверка питания, затем прошивка |
| Нет реакции на пульт, чёрный экран | есть ли лог UART? | нет лога → bootrom/питание/кварц; есть → читаем ошибку |
| Пропали MAC/Wi-Fi после прошивки | записан чужой дамп целиком | вернуть свой бэкап раздела с MAC/SN (factory/param) |
| ТВ не выходит из standby | шина I2C, питание подсветки | осциллограф; прошивка редко виновата |
| Обновление прервалось (отключили свет) | eMMC/NAND частично записан | программатор: стереть и записать полный дамп |

## Связка с boot_profiles.py

- UART-консоль загрузчика — первый источник диагностики (см. профили:
  Realtek/MediaTek/MStar/Amlogic/HiSilicon/Novatek).
- Если консоль молчит или команд нет — следующий уровень: EJTAG/
  программатор + дамп с ejtag.ru (поиск по модели платы/шасси, не по
  маркетинговому имени ТВ).
- Модель шасси читается с наклейки на плате (например, T.HV530.A82) —
  именно она нужна для поиска дампа.

## Источники для обучения (реестр)

| Источник | Что взято / что добывать |
|---|---|
| **ejtag.ru** | программаторы Tiny Tools (USB-F/USB-SPI/EASY-NAND/eJfinder), дампы eMMC/NAND, распиновки адаптеров, методика прошивки. Активный источник: пары «шасси ↔ дамп ↔ панель», решения проблем чтения/записи. Доступ к вложениям — официальным пользователям, закрытые разделы не парсить. |
| **4pda** | команды MStar (`recovery_wipe_partition`, вход в `Mstar#`, включение UART BUS), ветки по конкретным ТВ-шасси. Добывать: паттерны «симптом → команда консоли → результат». |
| **remont-aud.net** | вход в консоль Realtek, обсуждения ТВ-плат и прошивок. Добывать: комбинации входа в загрузчик по вендорам, опыт восстановления после неудачных прошивок. |
| **kenotrontv.ru** | обзоры доступа к терминалам Smart TV (в т.ч. MediaTek MT9632), заводские меню, методы диагностики через UART. |
| **mslw.com** | подтверждение методов входа в консоль загрузчиков (закрытые разделы — только для участников). |
| **televid-sib.org** | Первый Сибирский форум по ремонту телерадиоаппаратуры: ремонт ЖК/LED ТВ (10k+ сообщений), плазм, CRT, DVB-T2/ресиверов, раздел «Вопросы к мастерам», запросы дампов. Добывать: типовые аппаратные неисправности (БП, подсветка, T-CON, main-платы), кейсы «неисправность → диагностика → замена/прошивка». |

### Правила превращения форумов в обучающие данные

1. Пары «плата/шасси ↔ дамп ↔ версия панели» → таблица фактов для БД знаний.
2. Треды неисправностей → паттерн «симптом → причина → диагностика →
   команды/действия → результат» в обучающие примеры.
3. Каждую находку привязывать к профилю из `boot_profiles.py`
   (Realtek/MediaTek/MStar/Amlogic/HiSilicon/Novatek), если дело о
   загрузчике/UART.
4. Уважать правила форумов: не парсить закрытые/вложения без доступа,
   указывать источник у каждой записи.
